# 🩸 Anti Anemia - Sistem Informasi Kesehatan & Edukasi Obat

**Anti Anemia** adalah platform edukasi berbasis web modern dengan konsep *Landing Page* interaktif. Website ini dirancang untuk memberikan informasi yang komprehensif, edukatif, dan profesional mengenai penyakit anemia, jenis obat-obatan, aturan konsumsi, efek samping, hingga strategi pencegahan.

---

## 🚀 Fitur Utama Website

1. **Loading System Modern:** Animasi pemuatan bersumbu DNA medis (*Loading Medical System...*).
2. **Desain Modern Medical Tech:** Penerapan UI/UX bersih, efek glassmorphism, warna bertema medis, serta dukungan **Dark Mode & Light Mode**.
3. **Edukasi Komprehensif:** 
   - Pengertian, Penyebab, Gejala (5L), dan Faktor Risiko Anemia.
   - Penggolongan Obat: Suplemen Zat Besi (Ferrous Sulfate, Fumarate, Gluconate), Vitamin Pendukung (B12, Asam Folat), dan Terapi Medis (Erythropoietin).
   - Aturan pakai & larangan penggunaan obat sembarangan.
   - Efek samping (Mual, nyeri perut, perubahan warna feses, dll).
   - Edukasi pola hidup sehat & nutrisi pencegah anemia.
   - Strategi pemasaran & distribusi obat beretika.
4. **Timeline Interaktif:** Sejarah perkembangan obat anemia dari era tradisional hingga modern.
5. **Modal Popup Detail Obat:** Informasi interaktif obat tanpa berpindah halaman.
6. **Desain Responsif:** Tampilan optimal di perangkat Mobile, Tablet, dan Desktop.
7. **Animasi Partikel Canvas & Scroll Reveal:** Micro-interactions halus saat pengguna mengusap halaman.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur dokumen semantik dan aksesibel.
- **CSS3:** Flexbox, Grid, CSS Variables, Glassmorphism, dan Animations.
- **JavaScript (ES6):** Interaktivitas DOM, Observer API, Canvas API, dan LocalStorage.
- **Font Awesome 6 & Google Fonts:** Ikonografi medis dan tipografi Poppins / Inter.
